
# Final Project

This is my attempt at making a bullet hell game in pygame. I would like it to have multiple different patterns and a boss, and if I get the time a full level that is able to be played through.

## Assets
- [Photopea](https://www.photopea.com/)
- [BFXR](https://www.bfxr.net/)
- [Stylized Textures](https://freestylized.com/)
- [Open Game Art](https://opengameart.org/)
## Requirements
- Python 3+
- Pygame 2.6.1

## How to play:
Dodge all of the bullets! Get as many points as you can
- W A S D / Arrows to move
- Space bar to knock bullets back towards the evil cat
- Shift to slow down to dodge the bullets

## Installing / Running
1. Clone the repository
2. Run main.py
3. Hit all of the bullets!

# What is working
- The bullet patterns are being able to be cycled through
- The player interation with the bullets is working as intended 
- Score and game over screen are working
